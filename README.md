# Análise de dados: nível básico

Repositório de estudo e portfólio da minha trilha de **Analista de Dados**. Tudo aqui gira em torno de **um único projeto de vendas de e-commerce**, reaproveitado em SQL, Excel, Power BI e Python, para comparar resultados entre ferramentas.

## Projeto: vendas de um e-commerce brasileiro

**Pergunta de negócio:** como as vendas evoluíram ao longo do tempo, quais categorias e produtos mais geram receita e onde estão os problemas (pedidos cancelados ou não entregues)?

**Fonte dos dados:** [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (Kaggle). Dados públicos e anonimizados de cerca de 100 mil pedidos entre 2016 e 2018. Licença indicada na página do dataset: CC BY-NC-SA 4.0. Os arquivos **não** ficam neste repositório: veja [data/README.md](data/README.md) para baixar.

### Perguntas que o projeto vai responder
1. Qual a receita por mês e qual a tendência?
2. Quais categorias e produtos têm mais receita e mais unidades vendidas?
3. Como se distribuem os status dos pedidos (entregue, cancelado, etc.)?
4. Como a receita varia por estado do cliente?
